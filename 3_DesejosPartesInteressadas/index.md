# Desejos das Partes Interessadas

| Categoria | Parte interessada | Desejo |
| --------- | ----------------- | ------ |
| Must have | Líder do ministério | Publicar a enquete de disponibilidade |
| Must have | Líder do ministério | Montar a escala |
| Must have | Professores voluntários | Receber a escala, com link para os materiais das aulas em que está escalado |
| Should have | Professores voluntários | Receber notificação de que a enquete de disponibilidade está acessível para ser respondida |
| Should have | Líder do ministério | Receber infomação de quantos já responderam |
| Could have | Líder do ministério | Prorrogar o prazo de resposta à enquete de disponibilidade |
| Could have | Líder do ministério | Editar a escala |
| Won't have | Editora das revistas de lições | Encomendar automaticamente as revistas |
