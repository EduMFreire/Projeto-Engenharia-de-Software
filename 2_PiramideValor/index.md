# Pirâmide do Valor
## Premissas
Vamos analisar o projeto da perspectiva B2B. Isto é, vamos elencar os elementos de valor que mais podem levar uma igreja, enquanto organização, a adotar o programa de gestão de escala de voluntários do ministério infantil.

Afinal, se uma pessoa, enquanto cliente individual, quiser adotar o projeto, ela não necessariamente consegue: é necessário que todos os voluntários de forma padronizada instalem o programa.

## Elementos de valor principais da pirâmide B2B
Estes são os principais elementos de valor oferecidos pelo projeto, do mais relevante para o menos relevante:

- Reduced effort

    O projeto torna a montagem da escala mais fácil.

- Decreased hassles

    Com as notificações enviadas pelo programa, não é mais necessário lembrar os voluntários de que eles precisam preencher a escala. Isso é um transtorno que é evitado; afinal, lembrar uma mesma pessoa múltiplas vezes pode gerar estresse e conflitos.

- Time savings

    O projeto poupa tempo da líder do ministério na hora de montar a escala. Ela não precisa mais ficar construindo possíveis escalas manualmente enquanto busca uma viável.

- Scalability

    Em um cenário com várias dezenas de voluntários, a montagem manual da escala se torna realmente inviável. O projeto supera essa limitação.

## Elementos de valor secundários
Os seguintes elementos de valor podem, em certo sentido, ser associados ao projeto. Contudo, nós não os descreveríamos como os mais importantes:

- Product quality

    Com o projeto, a tendência é que haja voluntários capazes preenchendo a maioria dos dias de aula. Isso aumenta a qualidade do serviço do ministério infantil. Contudo, isso não é uma característica que o projeto controla diretamente: mesmo que a gestão da escala seja muito boa, se não houver voluntários suficientes, então não será possível preencher todos os dias de aula.

- Simplification, Organization

    O projeto mantém a escala simples e fácil de acompanhar. Contudo, poder-se-ia argumentar que as enquetes no WhatsApp já são simples para os voluntários. O projeto apenas simplifica a gestão para a líder do ministério.

- Information, Transparency

    A escala se torna fácil de ver no aplicativo. Contudo, mesmo sem o projeto, a escala já pode ser transparente: para isso, basta enviá-la em um grupo de WhatsApp.
